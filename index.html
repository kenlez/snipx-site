▦ feature-menu.webp

常驻菜单栏

点击即开，不打扰

SnipX 始终浮于屏幕角落的菜单栏。无需打开主窗口，点击即弹出截屏 / 录屏入口。

  • 截屏、录屏、标注、设置 全部直达
  • 不抢焦点、不打扰当前工作
  • 原生菜单栏图标，遵循 macOS 设计语言
⌃ feature-shortcut.webp

可编辑快捷键

全局快捷键，自由绑定

截屏、录屏、标注、长截图 — 每个动作都可绑定独立快捷键，避免与其他应用冲突。

  • 支持单键 / 组合键 / 修饰键
  • 冲突检测，一键恢复默认
  • 录屏、截屏独立绑定，标注即时唤起
▢ feature-modes.webp

四类截屏

区域 / 窗口 / 全屏 / 长截图

物理像素输出，自动按显示器倍率渲染。窗口截屏自动识别应用窗口边缘，长截图无缝拼接。

  • 区域截屏：拖拽选区，物理像素精度
  • 窗口截屏：自动选窗，背景透明
  • 全屏截屏：多显示器同时输出
  • 长截图：滚动拼接，自动对齐
⌗ feature-ocr.webp

本地 OCR（0.1.99 新增）

截图里的文字，一键识别

基于 Apple Vision 框架，在你的 Mac 上直接识别截图中的中文、英文与中英混合文本。识别结果可编辑、可复制，不上传任何内容。

  • 中文（简/繁）、英文与中英混排
  • 完全本地识别，截图与文字不出本机
  • 识别后可编辑、复制或取消
  • 适用于截屏后的二次编辑与提取
✎ feature-annotation.webp

标注工具

矩形 / 箭头 / 文字 / 马赛克

截屏后即时标注，所有元素可移动、可删除、可撤销重做。裁剪、马赛克、颜色选择器一应俱全。

  • 矩形、椭圆、箭头、画笔、文字
  • 马赛克模糊敏感信息
  • 撤销 / 重做 / 裁剪 / 颜色选择器
● feature-recording.webp

本地 MP4 录屏 · SnipX Pro

倒计时 · 系统声 + 麦克风 · 自动恢复

基于 ScreenCaptureKit 本地录制，支持同时录制系统声音与麦克风，倒计时、磁盘保护、异常恢复一应俱全。头尾裁剪导出，无需第三方编辑器。

  • 区域 / 窗口 / 显示器三种录屏模式
  • 系统声音与麦克风同时录制，单一音轨
  • 倒计时与状态指示，录屏不打断
  • 异常退出后 Recovery 保留录制
  • 头尾裁剪导出为新 MP4

录屏与 GIF 录制需解锁 SnipX Pro（一次性买断，价格以 App Store 为准）。截屏、标注、长截图永久免费。

⏻ feature-privacy.webp

零数据外传

完全离线运行

截图、录屏与 OCR 在本机处理，不自动上传内容或遥测。购买与恢复通过 Apple 服务完成。

  • 购买与恢复可能需要联网
  • 无账号、无登录、无云同步
  • 无第三方 SDK、无埋点
  • 开源友好的本地存储

关于 SnipX

原生开发

Swift + AppKit + SwiftUI + ScreenCaptureKit + AVFoundation + Carbon 编写，无 WebView、无 Electron、无包装层。

隐私优先

内容处理在本机，无需注册 SnipX 账号。购买由 Apple 处理；主动分享由你选择。详见 隐私政策。

SnipX Pro

截屏、标注、长截图、置顶永久免费。一次性买断解锁 MP4 录屏与 GIF 录制，价格以 App Store 为准。

持续维护

当前版本 0.1.99。每个版本均经过手测、单元测试、功能测试三道关。需要帮助？ 支持页。
