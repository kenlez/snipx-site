特性

▦ feature-menu.webp

常驻菜单栏

点击即开，不打扰

snipX 始终浮于屏幕角落的菜单栏。无需打开主窗口，点击即弹出截屏 / 录屏入口。

  • 截屏、录屏、标注、设置 全部直达
  • 不抢焦点、不打扰当前工作
  • 原生菜单栏图标，遵循 macOS 设计语言
⌃ feature-shortcut.webp

可编辑快捷键

全局快捷键，自由绑定

截屏、录屏、标注、长截图 — 每个动作都可绑定独立快捷键，避免与其他应用冲突。

  • 支持单键 / 组合键 / 修饰键
  • 冲突检测，一键恢复默认
  • 录屏、截屏独立绑定，标注即时唤起
▢ feature-modes.webp

四类截屏

区域 / 窗口 / 全屏 / 长截图

物理像素输出，自动按显示器倍率渲染。窗口截屏自动识别应用窗口边缘，长截图无缝拼接。

  • 区域截屏：拖拽选区，物理像素精度
  • 窗口截屏：自动选窗，背景透明
  • 全屏截屏：多显示器同时输出
  • 长截图：滚动拼接，自动对齐
✎ feature-annotation.webp

标注工具

矩形 / 箭头 / 文字 / 马赛克

截屏后即时标注，所有元素可移动、可删除、可撤销重做。裁剪、马赛克、颜色选择器一应俱全。

  • 矩形、椭圆、箭头、画笔、文字
  • 马赛克模糊敏感信息
  • 撤销 / 重做 / 裁剪 / 颜色选择器
● feature-recording.webp

本地 MP4 录屏

倒计时 · 状态指示 · 自动停止

基于 ScreenCaptureKit 本地录制，倒计时、磁盘保护、Recovery 保留一应俱全。头尾裁剪导出，无需第三方编辑器。

  • 倒计时与状态指示，录屏不打断
  • 磁盘空间不足自动停止，文件不损坏
  • 异常退出后 Recovery 保留录制
  • 头尾裁剪导出为新 MP4
⏻ feature-privacy.webp

零数据外传

完全离线运行

无网络请求、无账号体系、无遥测、无第三方依赖。所有截图、录屏数据始终留在你的 Mac。

  • 无网络请求（可通过 Little Snitch 验证）
  • 无账号、无登录、无云同步
  • 无第三方 SDK、无埋点
  • 开源友好的本地存储
