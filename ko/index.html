    SnipX

    Mac 스크린샷과 화면 녹화를 한 번의 탭으로.

    네이티브 AppKit + Swift + ScreenCaptureKit. 물리 픽셀 출력, 온디바이스 OCR, 편집 가능한 단축키, 스크롤 캡처, 로컬 MP4 녹화까지. 모든 처리는 Mac에서 이루어지며 SnipX 계정 가입은 필요 없습니다.

    SnipX 다운로드 기능 보기

    기능

    메뉴바에 상주, 보이는 대로 캡처

    캡처, 주석, 녹화, 스크롤 캡처까지 메뉴바에서 한 번의 탭으로.

    메뉴바 상주

    탭하면 열리고, 방해하지 않음

    SnipX는 화면 구석 메뉴바에 조용히 상주합니다. 메인 창을 열 필요 없이 한 번의 탭으로 캡처 / 녹화 진입점이 나타납니다.

    • 캡처, 녹화, 주석, 설정 한 번에 접근
    • 포커스를 빼앗지 않고 작업 흐름을 깨지 않음
    • macOS 디자인 언어를 따르는 네이티브 메뉴바 아이콘

    편집 가능한 단축키

    전역 단축키를 자유롭게 지정

    캡처, 녹화, 주석, 스크롤 캡처 — 모든 동작에 독립적인 단축키를 지정할 수 있고, 충돌 시 미리 경고합니다.

    • 단일 키 / 조합 키 / 보조 키 지원
    • 충돌 감지 및 원 클릭 기본값 복원
    • 녹화와 캡처 독립 바인딩, 주석 즉시 호출

    네 가지 캡처 모드

    영역 / 창 / 전체 화면 / 스크롤

    물리 픽셀 출력으로 디스플레이 배율에 맞춰 자동 렌더링. 창 캡처는 앱 창 가장자리를 자동 인식하고, 스크롤 캡처는 매끄럽게 이어 붙입니다.

    • 영역 캡처: 드래그 선택, 물리 픽셀 정밀도
    • 창 캡처: 자동 선택, 배경 투명
    • 전체 화면 캡처: 여러 디스플레이 동시 출력
    • 스크롤 캡처: 자동 이어 붙이기, 어긋남 없음

    온디바이스 OCR (1.0.0 신규)

    캡처 안의 텍스트를 한 번의 탭으로 인식

    Apple Vision 프레임워크 기반으로 Mac에서 직접 중국어, 영어, 중영 혼합 텍스트를 인식합니다. 결과는 편집 및 복사 가능하며, 어떤 내용도 업로드하지 않습니다.

    • 간체 / 번체 중국어, 영어 및 중영 혼합
    • 완전 로컬 인식, 이미지와 텍스트는 Mac 밖으로 나가지 않음
    • 인식 후 편집, 복사 또는 취소 가능
    • 캡처 후 추가 편집 및 텍스트 추출에 적합

    주석 도구

    사각형 / 화살표 / 텍스트 / 모자이크

    캡처 직후 즉시 주석을 추가하고, 모든 요소를 이동, 삭제, 실행 취소 / 다시 실행할 수 있습니다. 자르기, 모자이크, 색상 선택기까지 모두 기본 제공.

    • 사각형, 타원, 화살표, 펜, 텍스트
    • 모자이크로 민감 정보 흐림 처리
    • 실행 취소 / 다시 실행 / 자르기 / 색상 선택기

    로컬 MP4 녹화 · SnipX Pro

    카운트다운 · 시스템 음성 + 마이크 · 자동 복구

    ScreenCaptureKit 기반 로컬 녹화로 시스템 음성과 마이크 동시 녹음을 지원하며, 카운트다운, 디스크 보호, 비정상 종료 복구까지 갖췄습니다. 머리와 꼬리를 잘라 내보내면 타사 편집기가 필요 없습니다.

    • 영역 / 창 / 디스플레이 세 가지 녹화 모드
    • 시스템 음성과 마이크를 단일 트랙에 동시 녹음
    • 카운트다운과 상태 표시로 녹화를 방해하지 않음
    • 비정상 종료 시 Recovery가 녹화를 보존
    • 머리와 꼬리를 잘라 새 MP4로 내보내기

    녹화와 GIF 녹화는 SnipX Pro (일회성 구매, 가격은 App Store 기준)의 잠금 해제가 필요합니다. 캡처, 주석, 스크롤 캡처는 영원히 무료입니다.

    데이터 외부 전송 없음

    완전 오프라인 작동

    캡처, 녹화, OCR은 Mac에서 처리되며 콘텐츠나 텔레메트리 자동 업로드는 없습니다. 구매와 복원은 Apple 서비스를 통해 처리됩니다.

    • 구매와 복구에는 인터넷 연결이 필요할 수 있음
    • 계정, 로그인, 클라우드 동기화 없음
    • 타사 SDK 및 트래커 없음
    • 开源友好的本地存储

    SnipX 정보

    네이티브 개발

    Swift + AppKit + SwiftUI + ScreenCaptureKit + AVFoundation + Carbon으로 작성. WebView, Electron, 래퍼 레이어 없음.

    프라이버시 최우선

    콘텐츠 처리는 Mac에서 이루어지며 SnipX 계정 가입이 필요 없습니다. 구매는 Apple이 처리하고 능동적 공유는 사용자가 선택합니다. 자세한 내용은 개인정보 처리방침。

    SnipX Pro

    캡처, 주석, 스크롤 캡처, 고정하기는 영구 무료. MP4 녹화와 GIF 녹화는 일회성 구매로 잠금 해제되며 가격은 App Store 기준입니다.
