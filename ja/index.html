    SnipX

    Mac のスクリーンショットと録画を、ワンタップで。

    ネイティブ AppKit + Swift + ScreenCaptureKit。物理ピクセル出力、デバイス内 OCR、編集可能なショートカット、スクロールキャプチャ、デバイス内 MP4 録画。すべての処理は Mac 上で完結し、SnipX アカウントの登録は不要です。

    macOS 14+ Universal 2 · Apple Silicon + Intel デバイス内 OCR SnipX Pro 録画/GIF

    SnipX をダウンロード 機能を見る

    機能

    メニューバーに常駐、見てすぐキャプチャ

    キャプチャ、注釈、録画、スクロールキャプチャを、メニューバーからワンタップで。

    メニューバーに常駐

    クリックで開く、邪魔しない

    SnipX は画面端のメニューバーに静かに常駐します。メインウィンドウを開かなくても、ワンクリックでキャプチャ / 録画の入口が現れます。

    • キャプチャ、録画、注釈、設定にワンタップでアクセス
    • フォーカスを奪わず、作業の邪魔をしない
    • macOS のデザイン言語に準拠したネイティブのアイコン

    編集可能なショートカット

    グローバルショートカットを自由に割り当て

    キャプチャ、録画、注釈、スクロールキャプチャ — すべてのアクションに独立したショートカットを割り当てられ、競合があれば事前に警告します。

    • 単一キー / 組み合わせ / 修飾キーに対応
    • 競合検出とワンクリックでデフォルト復元
    • 録画とキャプチャは独立バインド、注釈は即時呼び出し

    4 つのキャプチャモード

    範囲 / ウィンドウ / フルスクリーン / スクロール

    物理ピクセル出力で、ディスプレイ倍率に合わせて自動レンダリング。ウィンドウキャプチャはアプリウィンドウの端を自動認識し、スクロールキャプチャは継ぎ目なく拼接します。

    • 範囲キャプチャ：ドラッグで選択、物理ピクセル精度
    • ウィンドウキャプチャ：自動選択、背景透明
    • フルスクリーンキャプチャ：複数ディスプレイを同時に
    • スクロールキャプチャ：自動拼接、ズレなし

    デバイス内 OCR（1.0.0 新機能）

    キャプチャ内の文字をワンタップで認識

    Apple Vision フレームワークにより、Mac 上で直接キャプチャ内の中国語・英語・中英混在テキストを認識します。結果は編集・コピー可能で、何もアップロードしません。

    • 簡体字・繁体字・英語および中英混在
    • 完全ローカル認識、画像とテキストは Mac 内
    • 認識後に編集、コピー、キャンセルが可能
    • キャプチャ後の編集やテキスト抽出に最適

    注釈ツール

    四角形 / 矢印 / テキスト / モザイク

    キャプチャ直後にすぐに注釈を追加でき、すべての要素は移動・削除・Undo / Redo が可能。クロップ、モザイク、カラーピッカーも標準搭載。

    • 四角形、楕円、矢印、ペン、テキスト
    • モザイクで機密情報をぼかす
    • 元に戻す / やり直し / クロップ / カラーピッカー

    デバイス内 MP4 録画 · SnipX Pro

    カウントダウン · システム音声 + マイク · 自動復元

    ScreenCaptureKit ベースのローカル録画で、システム音声とマイクの同時録音に対応。カウントダウン、ディスク保護、異常復元も万全。先頭と末尾をトリムして書き出せるので、サードパーティ製エディタは不要です。

    • 範囲 / ウィンドウ / ディスプレイの 3 つの録画モード
    • システム音声とマイクを 1 つのトラックに同時録音
    • カウントダウンと状態表示で録画を止めない
    • 異常終了時は Recovery が録画を保護
    • 先頭と末尾をトリムして新しい MP4 に書き出し

    録画と GIF 録画は SnipX Pro（買い切り、価格は App Store 準拠）のロック解除が必要です。キャプチャ、注釈、スクロールキャプチャは永久無料です。

    データは一切外部送信されません

    完全オフラインで動作

    キャプチャ、録画、OCR は Mac 上で処理され、コンテンツやテレメトリの自動アップロードは行いません。購入と復元は Apple のサービスを経由します。

    • 購入と復元にはネット接続が必要な場合があります
    • アカウント・ログイン・クラウド同期なし
    • サードパーティ SDK・トラッカーなし
    • オープンソースに配慮したローカルストレージ

    ダウンロード

    Mac App Store で入手

    App Store でワンクリックインストール。アプリ内課金、アップデート、購入復元は Apple が処理します。

    3. 3

    概要

    SnipX について

    ネイティブ開発

    Swift + AppKit + SwiftUI + ScreenCaptureKit + AVFoundation + Carbon で記述。WebView も Electron もラッパー層もありません。

    プライバシーを最優先

    コンテンツ処理はすべて Mac 上で完結し、SnipX アカウントの登録は不要です。購入は Apple が処理し、能動的な共有はあなたの選択次第です。詳しくは プライバシーポリシー。

    SnipX Pro

    キャプチャ、注釈、スクロールキャプチャ、ピン留めは永久無料。MP4 録画と GIF 録画は買い切りでロック解除、価格は App Store 準拠です。

    継続的にメンテナンス

    現在のバージョン 1.0.0。すべてのバージョンは手動テスト、ユニットテスト、機能テストの三段階をクリアしています。ヘルプが必要ですか？ サポートページ。
