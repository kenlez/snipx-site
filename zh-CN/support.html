    Support

    SnipX 支持与帮助

    FAQ、权限引导、反馈渠道 · 适用于 SnipX 1.0.0 及以上版本

    00

    系统要求

    • macOS 14.0 Sonoma 或更高版本
    • 支持 Apple Silicon（M1 / M2 / M3 / M4）和 Intel Mac
    • 通用构建（Universal 2）同时包含 arm64 和 x86_64
    • 截图、录屏与 OCR 在本机处理；商品加载、购买与恢复可能需要联网。
    01

    首次启动：权限引导

    SnipX 只会在你实际使用对应功能时申请系统权限，遵循 macOS 默认流程，不会启动即弹窗。

    1. 屏幕录制：首次截屏或录屏时系统会弹窗。授权后到「系统设置 → 隐私与安全性 → 屏幕录制」可看到 SnipX。
    2. 麦克风：仅在你开启「录制麦克风」开关时申请。
    3. 摄像头：仅在你开启「录制摄像头」开关时申请。
    4. 系统声音：录制电脑声音时，按 macOS 的屏幕与系统音频录制权限提示操作。

    如果误点了「拒绝」，可以到「系统设置 → 隐私与安全性」手动开启；SnipX 内置的「权限」面板也会引导你跳转到对应位置。

    02

    FAQ

    Q1

    Q1：SnipX 联网吗？会上传我的截图吗？

    截图、录屏、OCR 与标注在本机处理，不会自动上传给开发者。购买与恢复通过 Apple 服务完成，可能需要联网；主动分享或发邮件时，内容按你的操作交给相应服务。

    Q2

    Q2：SnipX Pro 是什么？哪些功能需要付费？

    截屏、标注、长截图、置顶、复制、保存、分享等基础功能永久免费。SnipX Pro（一次性买断，价格以 Apple 购买界面为准）解锁：

    • MP4 录屏（选定区域 / 显示器）
    • GIF 录制
    • 系统声音 + 麦克风同时录制
    • 摄像头画中画
    • 倒计时与异常自动恢复
    • 头尾裁剪导出
    Q3

    Q3：如何恢复购买？

    打开 SnipX → 菜单栏 → 设置 → 录屏 → 付费墙卡底部「恢复购买」按钮。App 会通过 StoreKit 2 重新校验你的购买状态。

    Q4

    Q4：可以更换已授权的功能吗？

    截屏、标注、长截图的快捷键都可以在「设置 → 快捷键」中自定义，冲突时会自动提示。

    Q5

    Q5：为什么我截不到 SnipX 自己的窗口？

    SnipX 在录屏与截屏时会自动排除自身的菜单栏蒙层、操作浮层与录屏浮动条，避免污染画面。其他 SnipX 窗口（如设置、编辑录屏）默认会被正常捕获。

    Q6

    Q6：OCR 支持哪些语言？

    1.0.0 起，OCR 支持中文（简/繁）、英文及中英混合文本，由 Apple Vision 框架在本地完成识别，无网络依赖。

    Q7

    Q7：录屏文件保存在哪里？

    通过保存对话框导出到你选择的位置。录制过程文件保存在应用支持目录的 SnipX/Recovery 中，沙盒版位于 SnipX 的 macOS 容器内。应用会保留可恢复文件；退出前请先保存需要的内容。

    03

    反馈与问题上报

    如果你遇到 bug、有功能建议或希望贡献想法：

    • 邮箱：snipx@tongkun.top
    • 请附上：macOS 版本、SnipX 版本、复现步骤、必要时附截图或录屏
    • SnipX 在异常退出时会保留崩溃日志到 Library/Logs/SnipX/CrashLogs/（沙盒版位于应用容器内），提交问题时一并附上可大幅加快定位
