# SnipX-site 多语言（i18n）架构

> 适用：snipX-site 站点。设计于 2026-09 与 SnipX 0.1.99 上线准备同期落地。

## 1. 支持语言

| URL 前缀 | 语言 | HTML lang | og:locale | 翻译质量 |
|---|---|---|---|---|
| `/zh-CN/` | 简体中文 | zh-CN | zh_CN | 原文 |
| `/zh-TW/` | 繁體中文 | zh-TW | zh_TW | 详译 |
| `/en/` | English | en | en_US | 详译 |
| `/ja/` | 日本語 | ja | ja_JP | 详译 |
| `/ko/` | 한국어 | ko | ko_KR | 详译 |
| `/es/` | Español | es | es_ES | 机译（[MT]，待人工校） |
| `/pt/` | Português (BR) | pt-BR | pt_BR | 机译（[MT]，待人工校） |

## 2. URL 策略

**子目录多页**（SEO 友好、各语种独立可被搜索引擎索引）：

- 默认 `/` 路径：根据浏览器 `navigator.language` 或 `localStorage.snipx-lang`
  自动跳转到对应子目录；找不到匹配时渲染 7 语手动选择页
- `/zh-CN/`、`/en/`、`/ja/` 等子目录：固定语种入口，HTML 头部硬编码 lang 与 og:locale
- 同一页面在各语种下的文件名一致：`/zh-CN/privacy.html` ↔ `/en/privacy.html` ↔ `/ja/privacy.html`
- 切换语种时由 `assets/js/i18n.js` 自动保持当前页面（index / privacy / support）

> 不需要 Cloudflare Pages 的 `_redirects` 或 Workers；
> 根路径行为由 HTML 内联 JS 在浏览器侧处理。

## 4. 翻译字典与生成脚本

### `tools/build-i18n.py`

- **不参与运行时**：CF Pages 只服务生成的静态文件，脚本从未在生产环境执行
- **职责**：
  1. 读取中文模板（`body_index / body_privacy / body_support` 内置）
  2. 应用翻译字典（`T` dict，结构 `{lang: {zh_string: target_string, ...}}`）
  3. 长串优先替换，避免短串误命中
  4. 生成 7 语 × 3 页 = 21 个 HTML 到各自子目录
  5. 生成 3 个根路径 HTML（自动跳转 / 7 语选择器）
- **缺失字段回退 zh-CN**（开发期友好）
- **新加字符串**：先在 `body_*()` 模板写中文，再给每个语种加对应翻译；运行 `python3 tools/build-i18n.py` 重新生成

### 添加新语种

1. 在 `LANGS` 列表加新语种代码
2. 在 `META` 加 `html_lang` 和 `og_locale`
3. 在 `T` 加新语种字典
4. 重跑生成脚本

## 5. 资源引用约定

- 所有 assets 路径改为根相对（`/assets/...`），保证子目录访问正确
- 跨页链接：topbar / footer 用根相对（`/{lang}/privacy.html`）
- 同语种内跨页：body 中保留相对路径（`./privacy.html`），浏览器自动解析为同目录
- 同页锚点：保持相对（`#features`）

## 6. 语言切换器 UI

- 位置：topbar 右侧，主题切换按钮之前
- 视觉：胶囊按钮（显示当前语种简称 + 下拉箭头 ⌄）
- 下拉菜单：列出全部 7 个语种，当前项 `aria-selected="true"` 高亮
- 交互：
  - 点击按钮：展开 / 收起下拉
  - 点击语种链接：跳转到 `/{lang}/{currentPage}.html`；同时把选择持久化到 `localStorage.snipx-lang`
  - 点击外部 / Esc：关闭下拉
- a11y：`aria-haspopup="listbox"`、`aria-expanded`、`role="option"` / `role="listbox"`

## 7. 防 FOUC 与主题

- 主题切换（深 / 浅 / 系统）的 inline FOUC 防抖脚本在每个语言页 head 中重复
- 主题切换按钮的 `data-mode` 默认值由模板按 `zh-CN` 文案写入
  "主题：跟随系统"，生成时已替换为各语种译文
