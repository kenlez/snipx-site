    Support

    SnipX 支援與說明

    FAQ、權限引導、回饋渠道 · 適用於 SnipX 1.0.0 及以上版本

    系統需求

    • macOS 14.0 Sonoma 或更高版本
    • 支援 Apple Silicon（M1 / M2 / M3 / M4）與 Intel Mac
    • 通用建置（Universal 2）同時包含 arm64 与 x86_64
    • 截圖、錄螢與 OCR 在本機處理；商品載入、購買與復原可能需要連線。

    首次啟動：權限引導

    SnipX 只会在你实际使用对应功能时申请系统权限，遵循 macOS 默认流程，不会启动即弹窗。

    1. 屏幕录制：首次截屏或录屏时系统会弹窗。授权后到「系统设置 → 隐私与安全性 → 屏幕录制」可看到 SnipX。
    2. 麦克风：僅在你開啟「錄製麥克風」開關時申請。
    3. 摄像头：僅在你開啟「錄製攝影機」開關時申請。
    4. 系統聲音：錄製電腦聲音時，按 macOS 的螢幕與系統音訊錄製權限提示操作。

    如果误点了「拒绝」，可以到「系统设置 → 隐私与安全性」手动开启；SnipX 内置的「权限」面板也会引导你跳转到对应位置。

    FAQ

    Q1：SnipX 連線嗎？會上傳我的截圖嗎？

    截圖、錄螢、OCR 與標註在本機處理，不會自動上傳給開發者。購買與復原透過 Apple 服務完成，可能需要連線；主動分享或發郵件時，內容按你的操作交給相應服務。

    Q2：SnipX Pro 是什麼？哪些功能需要付費？

    一鍵永久免費。SnipX Pro（一次性買斷，價格以 Apple 購買介面為準）解鎖：

    • MP4 錄螢（選定區域 / 顯示器）
    • GIF 錄製
    • 系統聲音 + 麥克風同時錄製
    • 攝影機子母畫面
    • 倒數計時與異常自動復原
    • 頭尾裁剪匯出

    Q3：如何復原購買？

    打开 SnipX → 菜单栏 → 设置 → 录屏 → 付费墙卡底部「恢复购买」按钮。App 会通过 StoreKit 2 重新校验你的购买状态。

    Q4：可以更換已授權的功能嗎？

    截圖、標註、長截圖的快捷鍵都可以在「設定 → 快捷鍵」中自訂，衝突時會自動提示。

    Q5：為什麼我截不到 SnipX 自己的視窗？

    SnipX 在录屏与截屏时会自动排除自身的菜单栏蒙层、操作浮层与录屏浮动条，避免污染画面。其他 SnipX 窗口（如设置、编辑录屏）默认会被正常捕获。

    Q6：OCR 支援哪些語言？

    1.0.0 起，OCR 支援中文（简/繁）、英文及中英混合文本，由 Apple Vision 框架在本地完成识别，无网络依赖。

    Q7：錄螢檔案儲存在哪裡？

    透過儲存對話框匯出到你選擇的位置。錄製過程檔案儲存在應用支援目錄的 SnipX/Recovery 中，沙盒版位於 SnipX 的 macOS 容器內。應用程式會保留可復原檔案；退出前請先儲存需要的內容。

    回饋與問題回報

    如果你遇到 bug、有功能建議或希望貢獻想法：

    • 電子郵件：snipx@tongkun.top
    • 請附上：macOS 版本、SnipX 版本、重現步驟、必要時附截圖或錄螢
    • SnipX 在異常退出時會保留當機記錄到 Library/Logs/SnipX/CrashLogs/（沙盒版位于应用容器内），提交問題時一併附上可大幅加快定位
