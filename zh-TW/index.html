    特色

    選單列常駐，所見即可截

    截圖、標註、錄螢、長截圖，全部在選單列一觸即達。

    常駐選單列

    點擊即開，不打擾

    SnipX 始終浮於螢幕角落的選單列。無需打開主視窗，點擊即彈出截圖 / 錄螢入口。

    • 截圖、錄螢、標註、設定 全部直達
    • 不搶焦點、不打擾目前工作
    • 原生選單列圖示，遵循 macOS 設計語言

    可編輯快捷鍵

    全域快捷鍵，自由綁定

    截圖、錄螢、標註、長截圖 — 每個動作都可綁定獨立快捷鍵，避免與其他應用程式衝突。

    • 支援單鍵 / 組合鍵 / 修改鍵
    • 衝突偵測，一鍵恢復預設
    • 錄螢、截圖獨立綁定，標註即時喚起

    四類截圖

    區域 / 視窗 / 全螢幕 / 長截圖

    物理像素輸出，自動依顯示器倍率渲染。視窗截圖自動辨識應用程式視窗邊緣，長截圖無縫拼接。

    • 區域截圖：拖曳選取區，物理像素精度
    • 視窗截圖：自動選窗，背景透明
    • 全螢幕截圖：多顯示器同時輸出
    • 長截圖：捲動拼接，自動對齊

    本地 OCR（1.0.0 新增）

    截圖裡的文字，一鍵辨識

    基於 Apple Vision 框架，在你的 Mac 上直接辨識截圖中的中文、英文與中英混合文字。辨識結果可編輯、可複製，不上傳任何內容。

    • 中文（簡/繁）、英文與中英混排
    • 完全本地辨識，截圖與文字不出本機
    • 辨識後可編輯、複製或取消
    • 適用於截圖後的二次編輯與擷取

    標註工具

    矩形 / 箭頭 / 文字 / 馬賽克

    截圖後即時標註，所有元素可移動、可刪除、可復原重做。裁剪、馬賽克、顏色選擇器一應俱全。

    • 矩形、橢圓、箭頭、畫筆、文字
    • 馬賽克模糊敏感資訊
    • 復原 / 重做 / 裁剪 / 顏色選擇器

    本地 MP4 錄螢 · SnipX Pro

    倒數計時 · 系統聲 + 麥克風 · 自動復原

    基於 ScreenCaptureKit 本地錄製，支援同時錄製系統聲音與麥克風，倒數計時、磁碟保護、異常復原一應俱全。頭尾裁剪匯出，無需第三方編輯器。

    • 區域 / 視窗 / 顯示器三種錄螢模式
    • 系統聲音與麥克風同時錄製，單一音軌
    • 倒數計時與狀態指示，錄螢不打斷
    • 異常退出後 Recovery 保留錄製
    • 頭尾裁剪匯出為新 MP4

    錄螢與 GIF 錄製需解鎖 SnipX Pro（一次性買斷，價格以 App Store 為準）。截圖、標註、長截圖永久免費。

    截圖、錄螢與 OCR 在本機處理，不自動上傳內容或遙測。購買與復原透過 Apple 服務完成。

    • 購買與復原可能需要連線
    • 無帳號、無登入、無雲端同步
